# Training

Reproducible stages:

| Stage | Command | Purpose |
|---|---|---|
| 1 Pretrain | `python training/train.py --config configs/model/20m.yaml` | language + structured JSON + tool heads |
| 2 Reasoning | SFT on educational explanations (`post_training/configs/reasoning.yaml`) |
| 3 Tool-use | LoRA or SFT (`post_training/configs/tool_use.yaml`) |
| 4 Education | quiz/plan/AR JSON |
| 5 Alignment | preference pairs in `post_training/datasets/` — **not** auto-applied |

Dataset: `edunova-hrm-synthetic-v1` generated by
`training/datasets/generate_synthetic.py`.

- Source: project-authored templates
- License: project-generated; no third-party corpora silently mixed in
- PII: none
- Split: 85/15 train/val written to `training/datasets/*.jsonl`

Checkpoints record parent, stage, tokenizer version, and metrics in
`train_metrics.json`.
