# PyTorch-first inference stack.
#
# VERSION PINS ARE LOAD-BEARING — do not loosen them without testing a real
# model load. `transformers>=4.56` refuses to load ANY .bin checkpoint unless
# torch>=2.6 is installed ("Due to a serious vulnerability issue in
# torch.load ... we now require users to upgrade torch to at least v2.6"), and
# transformers 5.x renamed/removed `torch_dtype=`. With the previous open range
# (`>=4.44,<5`) every rebuild silently resolved to the newest 4.5x release
# against torch 2.4 and the model failed at from_pretrained -> the service
# never reached READY. Upper bounds keep the deployed matrix reproducible.
transformers>=4.44.0,<4.56.0
